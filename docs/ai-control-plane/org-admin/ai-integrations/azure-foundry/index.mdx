Microsoft Foundry Agent Service runs agents that call tools over MCP. AI Control Plane MCP servers are remote MCP servers, so Foundry agents can call them with the same governance, tool logs, and per-user identity that apply to every other client.

<Callout title="When to use this integration" type="info">
  This integration is most useful when building agents in Foundry Agent
  Service. For most common MCP use cases, such as employees using Claude,
  Cursor, or Copilot on their own machines, use the [device
  agent](/docs/ai-control-plane/org-admin/device-agent) integration instead.
</Callout>

## Guides

- **Private tool catalog**: publish Speakeasy MCP servers to an organization-scoped catalog in Azure API Center, secured with OAuth, so Foundry developers can discover them under **Build > Tools**; see [Private tool catalog](/docs/ai-control-plane/org-admin/ai-integrations/azure-foundry/private-tool-catalog) for setup
