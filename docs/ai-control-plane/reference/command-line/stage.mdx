---
title: speakeasy stage
description: "Stage changes to a deployment configuration."
---

The `stage` command adds sources to a deployment config that can later be passed
to `speakeasy push`. These sources may include function zip files or OpenAPI
documents. If the config file doesn't exist yet, the command creates it.

The `stage` command is a parent command that contains the following subcommands:

- **[`speakeasy stage function`](/docs/ai-control-plane/reference/command-line/stage-function):** Stage a
  function zip file.
- **[`speakeasy stage openapi`](/docs/ai-control-plane/reference/command-line/stage-openapi):** Stage an
  OpenAPI document.

## Usage

```bash
speakeasy stage [subcommand] [subcommand options]
```

## Options

### <code>config</code>

This specifies the path to the deployment config file. Its default value is `speakeasy.deploy.json` in the
current working directory.

```bash
speakeasy stage --config ./path/to/my-deploy-config.json [subcommand] [subcommand options]
```
