The `speakeasy stage function` command stages a function zip file to a deployment configuration.

<Callout className="mt-8!">
    For more information on the base behavior of the `speakeasy stage` command, see the
    [`speakeasy stage` reference](/docs/ai-control-plane/reference/command-line/stage).
</Callout>

For a Functions Framework project, `speakeasy functions stage` stages the built
zip without these flags, and `speakeasy functions push` builds, stages, and
deploys in one step. See [Build and deploy](/docs/ai-control-plane/mcp-gateway/building-servers/functions/build-deploy).

## Usage

```bash
speakeasy stage function --slug my-function --location ./path/to/function.zip
```

## Options

### <code>slug</code> (required)

This adds the slug to identify the source.

```bash
speakeasy stage function --slug my-function [command options]
```

### <code>location</code> (required)

This specifies the location of a zip file containing function code. It can be a local file or a URL.

```bash
speakeasy stage function --location ./path/to/function.zip [command options]
```

### <code>name</code>

This adds a human-readable name for the source. If not specified, the name defaults to the slug.

```bash
speakeasy stage function --name "My Function" [command options]
```

### <code>runtime</code>

This specifies the runtime environment for the function. Supported values are
`nodejs:22` and `nodejs:24`. If not specified, it defaults to `nodejs:22`.

```bash
speakeasy stage function --runtime nodejs:22 [command options]
```

### <code>scale</code>

This specifies the number of instances to run for the function.

```bash
speakeasy stage function --scale 2 [command options]
```

### <code>memory-mib</code>

This specifies the amount of memory in MiB to allocate for the function (1 MiB = 1,024 x 1,024 bytes).

```bash
speakeasy stage function --memory-mib 256 [command options]
```
