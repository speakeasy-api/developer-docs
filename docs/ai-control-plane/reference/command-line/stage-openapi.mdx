The `speakeasy stage openapi` command stages an OpenAPI document to a deployment configuration.

<Callout className="mt-8!">
    For more information on the base behavior of the `speakeasy stage` command, see the
    [`speakeasy stage` reference](/docs/ai-control-plane/reference/command-line/stage).
</Callout>

## Usage

```bash
speakeasy stage openapi --slug my-openapi-doc --location ./path/to/openapi.yaml
```

## Options

### <code>slug</code> (required)

This specifies a slug to identify the source of the OpenAPI document.

```bash
speakeasy stage openapi --slug my-openapi-doc [command options]
```

### <code>location</code> (required)

This specifies the location of an OpenAPI document (in JSON or YAML format). The location can be a local file or a URL.

```bash
speakeasy stage openapi --location ./path/to/openapi.yaml [command options]
```

### <code>name</code>

This adds a human-readable name for the source. If not specified, the name defaults to the slug.

```bash
speakeasy stage openapi --name "My OpenAPI Document" [command options]
```
